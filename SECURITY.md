# Sicherheitslücken melden

Wenn Sie eine Sicherheitslücke in einer Website oder einem Repository der Anocs KG vermuten,
melden Sie sie bitte vertraulich per E-Mail an **security@mail.anocs.at** und nicht über
öffentliche Issues oder Pull Requests.

Hilfreich sind die betroffene Adresse oder Datei, eine kurze Beschreibung, die Schritte zum
Nachvollziehen und wie wir Sie erreichen. Wir bestätigen den Eingang und halten Sie auf dem
Laufenden, bis die Lücke geschlossen ist. Bitte nutzen Sie eine Lücke nur so weit, wie es für
den Nachweis nötig ist, und greifen Sie nicht auf fremde Daten zu.

## Reporting a vulnerability

Please report suspected vulnerabilities in any Anocs KG website or repository privately to
**security@mail.anocs.at**, not through public issues or pull requests. Include the affected URL
or file, a short description, steps to reproduce and how to reach you. German or English is
fine.
